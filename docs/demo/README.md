# One-minute Speak demo

The rendered demo is `speak-demo.mp4`. It uses repository screenshots rather than synthetic UI so every visible product claim is traceable to the released app.

## Timeline

- 0–6s: logo and positioning — “Private voice writing for Windows.”
- 6–18s: Dictate — global shortcut, natural speech, polished output.
- 18–29s: History — reopen and reuse local transcripts.
- 29–40s: Dictionary — teach names, products, and technical vocabulary.
- 40–50s: Voice profile — corrections and progress stay visible.
- 50–56s: Audio studio — optional local voice tools.
- 56–60s: Community download and Founding 100 call to action.

Rebuild it with `marketing/render-demo.ps1`. The script needs FFmpeg and uses only tracked images and text overlays.
