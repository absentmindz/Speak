# One-minute Speak demo

The rendered demo is [`speak-demo.mp4`](speak-demo.mp4). It uses repository screenshots rather than synthetic UI so every visible product claim is traceable to the app.

## Timeline

- 0–6s: logo and positioning — private, local-first voice writing for Windows.
- 6–18s: Dictate — global shortcut, natural speech, polished output.
- 18–28s: History — reopen and reuse local transcripts.
- 28–38s: Dictionary — teach names, products, and technical vocabulary.
- 38–47s: Voice profile — corrections and progress stay visible.
- 47–54s: Audio studio — optional local voice tools.
- 54–60s: supported launch and Community-source call to action.

## Original soundtrack

“Quiet Momentum” is a project-original, deterministic ambient/electronic bed created for this demo. It is generated by [`marketing/generate_demo_music.py`](../../marketing/generate_demo_music.py) from additive oscillators, chord-derived pulses, and synthetic early reflections. It contains no samples, stock recordings, AI-generated audio, or other third-party material. The composition and generated asset are distributed under the repository’s Apache-2.0 license.

The tracked source asset is [`marketing/audio/speak-demo-original-bed.m4a`](../../marketing/audio/speak-demo-original-bed.m4a), a lossless 48 kHz stereo ALAC file. During the final render, FFmpeg applies 2.5-second and 4-second fades, targets -21.5 LUFS with a -2.5 dBTP ceiling, and encodes AAC-LC at approximately 128 kb/s. Playback remains user-controlled on the website; the render pipeline does not enable autoplay.

## Rebuild

Run from the repository root:

```powershell
./marketing/render-demo.ps1
```

The PowerShell wrapper needs Python with Pillow plus FFmpeg; `-RegenerateMusic` also needs NumPy. It includes the tracked original soundtrack by default. Its media options are:

```powershell
# Re-synthesize the lossless source bed, then render the demo.
./marketing/render-demo.ps1 -RegenerateMusic

# Render a backward-compatible, video-only MP4.
./marketing/render-demo.ps1 -NoMusic

# Mix a different locally licensed soundtrack.
./marketing/render-demo.ps1 -MusicPath "C:\path\to\music.wav"
```

The underlying Python renderer also keeps `--music` optional. See [`media-manifest.json`](media-manifest.json) for current delivery properties, provenance, hashes, and validation measurements.
