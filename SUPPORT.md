# Support

Speak is a community pre-release project.

- Questions and reproducible bugs:
  [GitHub Issues](https://github.com/absentmindz/Speak/issues)
- Feature ideas:
  [feature request form](https://github.com/absentmindz/Speak/issues/new?template=feature_request.yml)
- Vulnerabilities:
  [private security advisory](https://github.com/absentmindz/Speak/security/advisories/new)

Before sharing logs or screenshots, remove transcripts, recordings, API keys,
authorization headers, usernames, local paths, notifications, and taskbar
details. Never upload `appsettings.json`, `.env` files, or history exports as
public attachments.
